# ameriflux-mcp — implementation plan (2026-10-22)

## Context

No MCP server exists for AmeriFlux or FLUXNET data. Searches of the MCP registry for "ameriflux" and "fluxnet" return 0 results, and the GitHub repo `flux-net/FLUXNET-MCP` is empty. We want agents to be able to:

- find eddy-covariance sites;
- check which data products and years exist;
- understand the FLUXNET variable grammar;
- cite data correctly under the right data policy;
- download (with consent) and preview data for the AmeriFlux products (BASE, BADM/BIF, AmeriFlux FLUXNET) and FLUXNET2015 FULLSET/SUBSET.

The target directory `/home/tswetnam/github/idss-mesa/ameriflux-mcp` is empty and is not a git repo. The new server is a sibling of `edi-mcp` and `neon-mcp`:
- **edi-mcp** is the core template: registry, server adapter, envelope, config, errors, transports, test harness, fixtures and docs scripts.
- **neon-mcp** supplies downloads, rate limiting, fuzzy resolve, prompts, Dockerfile and release.yml.

Both D-registers apply wherever this plan is silent.

**Research.** The facts were gathered live with GET requests only and checked adversarially. The full dossier, with evidence items E1–E47, is in `/tmp/claude-1000/-home-tswetnam-github-idss-mesa-ameriflux-mcp/22493784-58dd-49ac-8e25-7fbae661fd3c/scratchpad/dossier.md`, alongside `synth.md` and `final_plan.md`. Step 1 turns it into `RESEARCH.md`.

**Upstream facts that shape the design:**
- **The API is public but undocumented.** It is JSON on `amfcdn.lbl.gov/api/v1|v2`, with no OpenAPI spec. v1 and v2 are asymmetric (`v2/site_info_display/AmeriFlux` works; `v1/site_info_display` returns 404).
- **Lookups are anonymous GETs:**
  - the site catalog: 856 AmeriFlux sites, 1.7 MB, including 2,703 team emails;
  - `v1/data_availability/{net}/{prod}/{pol}`;
  - `v1/site_availability`;
  - `v1/fp_var` (145 variables);
  - `v1/DOI/{SITE}/{AmeriFlux|FLUXNET|FLUXNET2015}`, which returns versioned citations such as "Ver. 28-5";
  - `site_display/FLUXNET/{FLUXNET2015|FLUXNET-CH4}`, which returns 212 and 81 sites.
- **Invalid values fail silently on AmeriFlux.** An invalid enum on the AmeriFlux network returns **200 with empty rows**. Only the FLUXNET network returns 422.
- **Downloads disclose identity.** A download is one `POST v1/data_download` carrying user_id, email, intended_use and description. That text **is sent to the site PIs and to the download log**. The files it returns are static, unsigned files on `ftp.fluxdata.org` with ETags and no published checksums.
- **FLUXNET2015 is frozen and "outdated".** Downloading it needs a fluxnet.org login. Its metadata is anonymous. An open `paper_test/` index exists but is unofficial, so we never use it.
- **Policies escalate.** CC-BY-4.0 mixed with Legacy gives Legacy, and FLUXNET2015 Tier 1 mixed with Tier 2 gives Tier 2. Acknowledgment wording also differs: "data service" for CC-BY versus "data portal" for Legacy.

## Identity configuration

Identity comes from env and YAML only. It never comes from a flag, a tool argument, a cache key, a log line, the sidecar or the ledger.

| Field | Override variable | Fallback variable |
|---|---|---|
| user_id | `AMERIFLUX_MCP_IDENTITY__USER_ID` | `AMERIFLUX_USER_ID` |
| user_email | `…__USER_EMAIL` | `AMERIFLUX_USER_EMAIL` |
| user_name | `…__USER_NAME` | `AMERIFLUX_USER_NAME` |
| intended_use (codes 1–6) | `…__PROFILES__DEFAULT__INTENDED_USE` | `AMERIFLUX_INTENDED_USE` |
| description | `…__PROFILES__DEFAULT__DESCRIPTION` | `AMERIFLUX_DESCRIPTION` |
| is_test | `…__IS_TEST` | none |

- Additional profiles are defined in YAML only.
- Look-alike variables are warned about and not read: `AMERIFLUX_EMAIL`, `AMERIFLUX_USERNAME`, `AMF_*`, `AMERIFLUX_TOKEN`, `AMERIFLUX_API_KEY`.
- Values are SecretStr and are registered with the log redactor. `--print-config` masks them.

**Download handler order (`confirm=true`):**
1. Validate against the matrix and map BIF to BASE-BADM.
2. Compute the effective policy and check `accept_data_policy` against it.
3. Check identity, profile and `is_test`; if missing, return `auth_required`.
4. Send one POST and record the returned URLs in the ledger.
5. Classify each URL against the allow-list; skip `FLUXNET-BIF` links.
6. HEAD each file and check the caps (50 files, 2 GiB per call, 1 GiB per file).
7. Stream to a `.part` file, then run the integrity checks (D16).
8. Rename the file and write the sidecar and an email-free manifest.

## Data handling

### Filenames (`files/filenames.py`, case-insensitive)

| Family | Pattern |
|---|---|
| BASE | `AMF_<S>_BASE_(HH\|HR)_<X-Y>.csv` and `AMF_<S>_BASE-BADM_<X-Y>.zip` |
| BIF | `AMF_<S\|AA-Net\|AA-Flx>_BIF_[CCBY4\|LEGACY_]YYYYMMDD.xlsx` |
| FLUXNET v1.x | Shuttle regex `v<N>[.<M>]_r<N>`; members `<NET>_<S>_FLUXNET_(FLUXMET\|ERA5\|BIFVARINFO)_(HH\|DD\|WW\|MM\|YY)_…`, plus `_BIF_` |
| FLUXNET2015 | `FLX_<S>_FLUXNET2015_(FULLSET\|SUBSET\|ERAI\|AUXMETEO\|AUXNEE)[_<RES>]_<Y-Y>_(<n-n>\|beta-<n>)` |
| FLUXNET-CH4 | Recognized only; no reader in v0.1 |

### Reading

- **zipsafe.** Check the central directory first. Reject absolute paths, `..`, symlinks, members over 1 GiB and compression ratios above 200. Stream members; never extract.
- **CSV.**
  - Capture leading `#` header lines (BASE has them; FLUXMET does not).
  - Require TIMESTAMP_START/END or TIMESTAMP, except for `aux_table` files.
  - Select columns by name.
  - Map `-9999`, `-9999.0` and `-9999.9` to null.
- **Timestamps.**
  - Parse by digit count (12, 8, 6 or 4).
  - Infer the step from START/END, because a v1.3 "HH" file can be hourly.
  - Handle END rolling into the next year.
  - Output local standard time plus `utcOffsetHours`, taken from BIF GRP_UTC_OFFSET via UTC_OFFSET_DATE_START.
- **Scan limits.** Stop at `end`, at 256 MiB, or after 20 s; then set `truncatedReason='budget'` and add a note pointing to the DD/MM files.
- **QA and QC.**
  - Count values outside the fp_var Min/Max ±5% as `outOfRange`; never drop them.
  - QC meaning depends on resolution: `_F_MDS_QC` is 0–3 at HH, and DD and coarser use fractions.

### Variables

**Grammar** (ported from amerifluxr `amf_parse_basename`): base name, then `_PI`, `_QC`, `_F`, `_IU`, then position (`_H_V_R`) or aggregation (`_H_V_A`, `_#`, `_SD`, `_N`), then the FLUXNET suffix lexicon:
- gap-filling: `_F_MDS`, `_ERA`, `_JSB`;
- USTAR filtering: `_VUT`/`_CUT` with `_REF`/`_USTAR50`/`_MEAN`/`_SE`/`_XX`;
- partitioning: `_NT`/`_DT`/`_SR`;
- uncertainty and other suffixes: `_RANDUNC`/`_JOINTUNC`, `_CORR*`, `_DAY`/`_NIGHT`.

Special cases: `FETCH_70/80/90`, `*_SSITC_TEST` and `FETCH_FILTER`.

**Dictionary build** (`scripts/build_vocabularies.py`, output committed with source and ETag):
- Fold the per-resolution rows into `unitsByResolution`.
- Treat "not available" and "not defined" as the same.
- Restore µ from U+FFFD.
- Take units from ONEFlux var_info, because many FULLSET Units cells are blank.

## Error mapping (no new codes)

| Upstream condition | Error |
|---|---|
| 404 | `not_found` |
| DOI `{}` or "No valid DOI" | `not_found` with a product hint |
| 422 | `invalid_argument` |
| Value outside the matrix | `invalid_argument` (`invalid_combination`), before any call |
| 405 or drift | `upstream_error` with `details.drift` |
| 429 | `rate_limited` |
| 52x or transport failure | `upstream_unavailable` |
| Download 4xx | `upstream_forbidden`, never a silent downgrade |
| URL off the allow-list or not in the ledger | `download_denied` |
| Caps exceeded | `download_limit_exceeded` |
| Length, ETag or CRC mismatch | `checksum_mismatch` |
| FLUXNET2015 or CH4 download | `feature_unavailable` |
